질문 1 · 배경Q1 · Background

한 세션에서 연구 논의를 이어갈 때 생기는 세 가지 문제 (Claude Code) Three problems when research discussion continues within one Claude Code session

한 세션에서 연구 논의를 이어가면 세부 내용으로 빠지고, 결론을 서두르고,
문서에 이전 결정이 덧붙여져 나열이 된다. When research discussion continues within one session, it drifts into details, reaches conclusions too early,
and documents turn into lists of earlier decisions.

문제Problem 한 세션의 예시 (illustrative, 지어낸 사례)Example from one session (illustrative, made up)
세부로 빠짐Drift 3번째 턴 사용자: "test 정확도가 왜 2점 떨어졌나?"
4~15번째 턴: data loader worker 수와 진행 표시줄 형식을 논의. 정확도 하락은 다시 다루지 않음Turn 3, user: "Why did test accuracy drop by 2 points?"
Turns 4-15: data loader worker count and progress bar format. The drop is not discussed again
이른 결론Early conclusions 16번째 턴 Claude: "label smoothing이 하락의 원인이다."
근거: seed 0 run 1개Turn 16, Claude: "Label smoothing caused the drop."
Basis: one run, seed 0
덧붙는 문서Appended documents 30번째 턴의 notes.md: "결정: lr 0.1" / "결정: lr 0.05" / "결정: warmup과 함께 lr 0.1".
어느 것이 현재 결정인지 적혀 있지 않음notes.md at turn 30: "Decided: lr 0.1" / "Decided: lr 0.05" / "Decided: lr 0.1 with warmup".
Which one is current is not stated

질문 1 · 목표와 달성 기준Q1 · Goal and success criteria

drive-project-forward의 목표와 미팅 단위 작업 순서 Goal of drive-project-forward and its order of work per meeting

목표를 GOAL.md 하나에 두고,
미팅마다 이해, 결정, 기록의 순서를 고정한다. The goal is kept in one document, GOAL.md,
and each meeting follows the fixed order: understand, decide, record.

  • 목표: "GOAL.md는 … 저장소 최상위에 둔다"Goal: "GOAL.md … is placed at the repository root"
  • 이해: "이 미팅의 목적은 사용자가 이해하는 것이다"Understand: "The purpose of this meeting is for the user to understand"
  • 결정: "결정하지 않는다. 결정받을 것은 선택지와 장단점으로 보인다"Decide: "It does not make decisions. Items to be decided are shown as options with pros and cons"
  • 기록: "미팅이 끝나면 … 미팅 노트를 쓰고, 사용자가 목표 자체를 조정했으면 GOAL.md를 고친다"Record: "After the meeting … Write the meeting note, and edit GOAL.md if the user adjusted the goal itself"
  • 달성 기준: 기록되지 않음. 이 저장소에는 GOAL.md가 없다Success criteria: not recorded. This repository has no GOAL.md
인용: skills/goal/SKILL.md 8행, skills/meet/SKILL.md 12·22·75행 (한국어는 번역)Quoted from skills/goal/SKILL.md line 8, skills/meet/SKILL.md lines 12, 22, 75
질문 2 · 접근 1/4Q2 · Approach 1/4

drive-project-forward의 미팅 주기 전체 구조 (스킬 4개, 기록 파일 2개) Full meeting cycle of drive-project-forward (4 skills, 2 record files)

GOAL.md는 처음 한 번 쓰고,
미팅 노트는 다음 미팅 자료의 리마인드가 된다. GOAL.md is written once,
and each meeting note becomes the reminder of the next meeting material.

질문 2 · 접근 2/4Q2 · Approach 2/4

노트 작성(④)에서 미팅 결과 종류별로 기록하는 위치 Where writing the note (④) records each kind of meeting outcome

목표 자체를 바꿀 때만 GOAL.md를 고치고,
방법 변경은 미팅 노트에만 남는다. Only a change to the goal itself edits GOAL.md;
method changes stay in the meeting note.

  • GOAL.md 수정: 문장을 교체하고,
    이력을 쓰지 않는다    Editing GOAL.md: replace sentences,
    keep no history

질문 2 · 접근 3/4Q2 · Approach 3/4

스킬이 만드는 슬라이드의 작성 규칙 (slides/RULES.md) Writing rules for the slides the skills generate (slides/RULES.md)

모든 장은 번호 붙은 질문 하나에 문장 하나로 답하고,
수치에는 조건과 출처를 붙인다. Every slide answers one numbered question with one sentence,
and numbers carry conditions and a source.

  • 장의 구성: 머리표, 명사구 제목, 한 문장 메시지, 불릿·구조도·표로 된 본문Structure: eyebrow, noun-phrase title, one-sentence message, body of bullets, diagrams, or tables
  • 구조도: 논문 수준의 구조도와 부분 확대 상세도Diagrams: paper-quality architecture diagrams, with zoomed-in details for parts
  • 색: 하늘색은 처음 보는 것, 빨간색은 중요한 것, c1~c4는 텍스트와 그림의 연결Colors: sky blue for first-time concepts, red for important items, c1-c4 to link text and visuals
  • 언어: 영어로 쓰고, 사용자 언어가 영어가 아니면 그 언어 토글을 추가한다Language: English, with a toggle for the user's language when it is not English

질문 2 · 접근 4/4Q2 · Approach 4/4

drive-project-forward의 설치 명령과 사용 순서 (Claude Code) Install commands and order of use for drive-project-forward (Claude Code)

설치 명령 두 개를 실행한 뒤,
goal, 미팅 전후의 meet, wrapup 순서로 쓴다. After two install commands,
the skills are used in the order goal, meet before and after each meeting, then wrapup.

  • 설치:Install: /plugin marketplace add JuwonHwang/drive-project-forward
    /plugin install drive-project-forward@drive-project-forward
  • 시작:Start: /drive-project-forward:goal → GOAL.md 작성→ creates GOAL.md
  • 미팅마다: 미팅 전Each meeting: before, /drive-project-forward:meet, 미팅 뒤 "summarize the meeting"; after, "summarize the meeting"
  • 공유:Sharing: /drive-project-forward:wrapup. 논의로 슬라이드 만들기:. Slides from a discussion: /drive-project-forward:slides

질문 3 · 한계Q3 · Limitations

drive-project-forward에서 측정하거나 시험하지 않은 항목 (2026-10-29 기준) Items not measured or tested in drive-project-forward (as of 2026-10-29)

플러그인이 연구 세션에 주는 효과는 측정하지 않았다. The effect of the plugin on research sessions has not been measured.

  • 효과: 플러그인 사용 전후의 세부로 빠짐, 이른 결론, 문서 길이를 측정하지 않았다Effect: no measurement of drift, early conclusions, or document length with and without the plugin
  • 호출 문구: "summarize the meeting" 같은 영어 문구로 스킬이 호출되는지 시험하지 않았다Triggers: whether English phrases such as "summarize the meeting" invoke the skills has not been tested
  • 화면 캡처: 슬라이드 확인은 헤드리스 Chrome을 쓰고, Chrome이 없으면 캡처를 건너뛴다Screenshots: the slide check uses headless Chrome; without Chrome, the screenshot step is skipped
